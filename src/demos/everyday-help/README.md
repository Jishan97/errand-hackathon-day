# Everyday phone help — second demo

Serve older adults who prefer calling for ordinary help or a simple reminder. Use the same conversation, approval, durable-work and callback core as the developer demo.

Possible starting example: ask a normal question, request a reminder to water the plants, confirm the time, hang up and receive the reminder call. An existing reminder must not prevent unrelated conversation.

The owner will discuss the exact scenario later. This example is an outline, not an agreed full specification. Keep the detailed wording, follow-up/correction behavior and acceptance checks open for that discussion.

No phone flow, reminder scheduler or callback is implemented here. See [the delivery plan](../../../docs/PLAN.md).
