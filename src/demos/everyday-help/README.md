# Everyday phone help — second demo

## Selected contribution: Gmail by phone

The owner selected one-time Composio-managed Gmail connection, followed by email help through a phone call. This worktree supplies the connections page and bounded Gmail adapter. WhatsApp, Telegram, Calendar, Outlook, Drive and Notion are visible but disabled for this demo. The teammate owns the shared core and actual phone execution.

Rehearsal: find a fictional repair email, read it together, prepare a short message, correct the date, approve the exact recipient/text, then verify Gmail Sent before the shared core calls back. Saving a Gmail draft is a separate approved action. See [integration contracts and acceptance steps](../../../docs/GMAIL_INTEGRATION.md). Live OAuth, durable backend and phone flow remain unverified. The reminder idea below is historical context, not this slice's acceptance target.

Serve older adults who prefer calling for ordinary help or a simple reminder. Use the same conversation, approval, durable-work and callback core as the developer demo.

Possible starting example: ask a normal question, request a reminder to water the plants, confirm the time, hang up and receive the reminder call. An existing reminder must not prevent unrelated conversation.

The owner will discuss the exact scenario later. This example is an outline, not an agreed full specification. Keep the detailed wording, follow-up/correction behavior and acceptance checks open for that discussion.

No phone flow, reminder scheduler or callback is implemented here. See [the delivery plan](../../../docs/PLAN.md).
